# ScienceClaw Full Wordmark Design

## Goal

Show the full event name, “ScienceClaw,” anywhere the primary public header wordmark currently displays the abbreviated “CLAW.”

## Scope

- Keep the existing origami claw mark unchanged.
- Change the homepage header wordmark to “ScienceClaw.”
- Change the application-page header wordmark to “ScienceClaw.”
- Change the flyer brand heading to “ScienceClaw.”
- Rebuild generated flyer assets so exported materials match the source.
- Preserve all layout, colors, links, dates, and form content.

## Verification

Automated identity tests must reject a standalone “CLAW” wordmark and require “ScienceClaw” in all three public surfaces. The complete test and brand-verifier suites must pass after generated flyer assets are rebuilt.
